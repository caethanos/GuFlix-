# Guflix

Plataforma estática de aprendizagem de idiomas com trilhas gamificadas:

- **Unidade 05 — Salud y Bienestar**: saúde, estresse, relaxamento, diminutivos e alimentação.
- **Unidade 06 — Las Finanzas**: trueque, evolução do dinheiro, divisas, poupança e juros.
- **English — Chapter 6**: Past Continuous, Simple Past, when/while e adjetivos de emoção.

Os cartões identificam cada episódio como **Não iniciado**, **Em andamento** ou **Concluído**. XP, progresso e questões para revisão ficam salvos no navegador do estudante (`localStorage`). O site não precisa de servidor ou etapa de build.

## Publicar no GitHub Pages

1. Envie `index.html`, `styles.css` e `app.js` para a raiz do repositório.
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**, escolha a branch principal e a pasta `/ (root)`.
4. Salve. O GitHub Pages publicará o site no endereço indicado nessa tela.

As fontes usam Google Fonts, com fontes locais de reserva quando não houver conexão.
